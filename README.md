# Data+ Academy

Agenda and link hub for the Data+ Academy webinars: every block links to its live Qlik
sheet, screenshot, docs or recording.

Live: https://leitartgmbh.github.io/dataplus-academy/

- One folder per event: `1/` (24 Nov 2026), `2/` (16 Dec 2026, coming soon). The root
  forwards to the current edition.
- Content of an event: `<n>/content/academy.js`. New event: copy the previous folder.
- Run locally: `npm start` (https://localhost:3000, Qlik sheets open full screen) or open
  `1/index.html` directly (Qlik sheets open in a new tab).
- Keys: `1`–`9` jump to a block, `←` `→` step, `F` full screen, `Esc` closes the Qlik viewer.

Live Qlik sheets need a leitart Qlik Cloud login.
